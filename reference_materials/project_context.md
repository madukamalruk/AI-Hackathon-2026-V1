## Course Overview
- A 4-week virtual seminar on "Principles and Practice of Agentic Artificial Intelligence".
- Focuses on creating real modern generative AI systems and products spanning multiple areas in computer science.
- Leverages the Jac and Jaseci open source ecosystem and tooling (React, Javascript/Typescript, Python, FastAPI, and k8s) along with cutting edge agentic AI technologies (ByLLM, etc).
- Dichotomy of learning: updating weights vs. updating context (from learning representations/training to prompting/retrieval/agentic workflows).
- Teams of 1-2 people.

## Course Project: Personal Planning App in Jac
- **Goal**: Build a personal planning tool using Jac to organize life, coursework, tasks, goals, or schedule.
- **Components Required**: Server, Web frontend, Mobile app, CLI.
- **Key Feature**: Must include an *agentic workflow* that takes a planning goal, uses data/tools to perform multiple steps, and decides what to do next (e.g., proposing a schedule, checking conflicts).
- **Submission**: GitHub repository link.
